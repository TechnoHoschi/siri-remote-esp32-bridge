Siri Remote ESP32 Bridge

Firmware … direkt aus dem Browser auf den ESP32-S3 spielen.

  1. ESP32-S3 per USB an diesen Rechner stecken – mit einem Kabel, das Daten kann.
  2. Auf „Installieren“ klicken und den Anschluss des ESP auswählen.
  3. Warten, bis der Balken durch ist. Danach den ESP an den Mediaplayer stecken.
Dieser Browser kann keine USB-Geräte ansprechen. Bitte Chrome oder Edge auf einem Rechner verwenden. Die Installation braucht eine HTTPS-Seite.

Die Installation löscht den gesamten Flash des ESP, also auch eine bestehende Kopplung und alle Einstellungen. Für Updates eines laufenden Dongles lieber die …-ota.bin aus dem Release über dessen Weboberfläche einspielen.

Geht der ESP nicht von selbst in den Flash-Modus: BOOT gedrückt halten, RESET kurz tippen, BOOT loslassen, dann erneut auf „Installieren“.

English: Plug the ESP32-S3 into this computer, click the button above and pick its serial port. Installing erases the whole flash, including pairing and settings. Needs Chrome or Edge on a desktop. If the ESP does not enter flash mode by itself: hold BOOT, tap RESET, release BOOT, try again.
